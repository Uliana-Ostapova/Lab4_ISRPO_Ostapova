## Структура проекта
```
Lab4_ISRPO_Ostapova/
|--client/
|    |--about.html
|    |--index.html
|--docs/
|    |--markdown_examples.md
|--repo/
|--server/
|    |--Program.cs
|    |--server.csproj
|--terminal_practice/
|    |--data/
|    |    |--text.txt
|    |--logs/
|         |--app.log
|--README.md
```
В папке `client` находятся две HTML-страницы:

- `about.html` - страница с информацией об авторе.
- `index.html` - главная страница лабораторной работы.

В папке `server` находится консольное приложение на C#. Оно выводит информацию о студенте и предоставляет меню для просмотра ФИО, группы и текущей даты.

В папке `docs` находится файл `markdown_examples.md`, в котором представлены примеры использования Markdown.

В папке `repo` хранятся скриншоты, сделанные в ходе выполнения лабораторной работы.

В папке `terminal_practice` находятся две папки и файлы, созданные в ходе практической работы с терминалом.
